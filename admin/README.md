# TomBot Web 管理平台

管理平台使用 React、TypeScript 和 Vite，访问同源 `/api/v2/admin`。已实现管理员验证器登记、账户激活、登录、身份复验、退出及显式会话续期，用户目录、同步开户、进度查询、失败重试、隔离对账与一次性激活材料展示，以及供应商、模型、凭据版本、策略草稿、能力测试发布、撤销和默认策略操作。

这些页面调用真实管理协议，没有产品内演示数据或认证旁路。当前 `tomd` 已挂接管理接口及静态资源，部署配置见[应用组合说明](../server/internal/serverapp/README.md)；首位管理员的[本机引导命令与网页激活](../server/docs/admin-bootstrap.md)已接通，节点部署与真实能力探针仍待完成。账户禁用、角色与限额管理、策略按用户和机器人分配、价格编辑、用量、审计、任务、电脑运维和总览页面仍待补齐。

## 本地构建与检查

在本目录执行：

```sh
npm ci
npm run check
npm run test:e2e
```

`check` 包含格式、ESLint、TypeScript、Vitest 和生产构建。浏览器测试需要 Go 和匹配版本的 Playwright Chromium；通过 `npx playwright install chromium` 安装，也可用 `PLAYWRIGHT_BROWSERS_PATH` 指定隔离测试目录。测试启动正式 Go 静态处理器，在实际 CSP 下检查用户目录、深浅色、窄屏、模态焦点及模型草稿发布流程，并要求没有 CSP 违规；业务 API 仅在测试代码中拦截，不连接公网模型或真实用户容器。

`npm run dev` 启动本地开发服务；`npm run preview` 查看 `dist/`。单独运行前端无法提供账户和 API，不会自动创建测试管理员。正式联调必须与真实管理 API 同源部署在 HTTPS 下，不能通过关闭 Cookie、CSRF 或来源校验解决跨源问题。

## 认证与结果一致性

- 未登录时可进入管理员激活：验证一次性材料、手动登记验证器、设置密码并提交动态码。成功后清除材料并返回登录，提示等待新的动态码；激活请求不发送管理 Cookie 或 CSRF，只接受明确的完成响应。
- 登记材料只保留在当前页面内存，默认隐藏，返回或离开页面时清除并取消在途请求；历史页面恢复也不保留输入。未知激活结果转到登录核实，不自动重放；错误验证码可重新输入，失效材料回到起始步骤。
- 访问与续期凭据仅由服务端 HttpOnly Cookie 管理。页面只把 CSRF 值保存在内存；本地存储只记录主题偏好，不保存账户、激活材料、模型凭据或业务缓存。
- 管理请求设置同源凭据、禁止重定向和缓存，并验证响应结构及大小。登录失效会取消在途请求、清空业务界面；旧会话响应不能重新写入新会话。
- 会话续期由管理员显式触发，同标签页合并请求，多标签页使用浏览器锁串行轮换。会话已经过期或浏览器不支持该能力时要求重新登录，不回退到持久化浏览器凭据。
- 写请求不自动重放。`504 CREATE_PENDING` 读取原操作；创建回包丢失时冻结原参数，只允许显式复用原幂等键核对。关闭弹窗后可通过用户目录的创建进度继续查询。
- 创建状态来自服务端。`pending`、`running`、`reconciling` 和 `compensating` 均不代表成功；查询有界轮询，达到上限或连接失败后显示当前状态并提供刷新。
- 模型修订冲突或写入结果未知时，关闭弹窗并重新读取后再决定下一步，不推算修订或覆盖他人修改。创建草稿也会改变策略修订，界面重新读取后才允许发布。发布前明确提示实际能力测试及供应商调用。
- 激活材料只在专用弹窗中短暂显示，关闭即卸载；再次签发会废止旧材料。密码、动态码和供应商凭据提交后立即清空输入控件。

## 样式与部署

[ui/theme.css](../ui/theme.css) 与 [ui/controls.css](../ui/controls.css) 是客户端和管理平台共享的主题、按钮、表单及弹窗样式来源。管理端只增加网页布局与业务样式，不依赖 Electron IPC、窗口拖拽区或客户端品牌组件。

构建基路径固定为 `/admin/`。将 `dist` 作为只读构建产物与服务端成套发布，挂接 [Go 静态处理器](../server/web/admin/page.go)，或配置具有相同边界的同源反向代理。静态处理器在启动时检查并读取有限构建文件，禁止目录列表、任意路径和 HTML 回退，响应设置 CSP、禁止嵌入、禁止缓存和 MIME 嗅探保护；业务 API 仍逐项鉴权。缺少构建产物时拒绝启动该处理器。

本次没有新增数据库迁移或导入旧数据。回滚应成套回退理解相同 v2 协议的前端和 API；保留服务端开户操作、模型版本与审计，不用回滚重发未知写入。共享样式移动后，客户端也需要从同一仓库根布局构建。
