# 工作台视觉验收

工作台使用墨色和纸色主题。主文字为 14 逻辑像素，辅助文字为 13，标题保留字号与字重层级。用户消息在 680 逻辑像素的正文列中右对齐，占可用宽度的 82%。Bot 回复使用带细边框的圆角消息气泡，头像、名称与完整正文均在气泡中；头像、群组色带和成员选择采用同一身份色相规则。代码和用量数字使用随客户端分发的等宽字体。

Bot 会话不再使用横贯内容区的 Header。顶部悬浮显示当前 Bot 头像和名称，名称过长时单行省略；点击打开右侧详情，手机进入详情页。浮层不显示状态、模型和角色说明，四周可继续滚动消息。详情中的“管理私有记忆”和“编辑身份与策略”提供原功能入口，右侧面板内可直接收起。群组保留原会话标题与成员活动信息。

输入框悬浮覆盖在消息流底部，外围没有全宽背景面板；外框与正文列同宽，左边缘对齐 Bot 气泡、右边缘对齐用户气泡。消息可从输入框后方滚过，滚到底部时按覆盖层高度留白，确保最后一条消息完整可见。输入区采用一个完整圆角边框：左侧加号添加附件，右侧发送箭头在执行期间切换为停止按钮。已选择的附件位于输入边框内顶部，可删除；长文件名省略，多个附件自动换行，超高时独立滚动。文字区域支持原有多行、Enter 发送、Shift+Enter 换行和输入法组合；旁观禁用文字输入时仍可停止活动回合。错误提示与整个输入边框左右对齐并位于其上方。软键盘弹出时，通知、附件与输入视口共同受剩余高度约束，长草稿内部滚动，保留完整内容和发送按钮。此调整只更新客户端，无接口或存储迁移；回滚时安装上一版客户端即可。

在客户端运行 `flutter test test/chat_header_layout_test.dart test/chat_composer_test.dart test/chat_activity_test.dart test/chat_attachments_test.dart test/chat_bubbles_test.dart test/sidebar_colors_test.dart test/workbench_notices_test.dart`，验证悬浮头像名称、详情入口、长名称、移动端和大字体布局、框内按钮、输入法、附件、停止及草稿保留，并核对气泡中的表格、流式中断和两种侧栏配色。

两种主题使用指定灰阶：浅色侧栏 `#F5F5F5`、内容区域 `#FCFCFC`、消息气泡 `#EFEFEF`；深色侧栏 `#0E0E0E`、内容区域 `#121212`、消息气泡 `#1E1E1E`。侧栏选中背景固定为浅色 `#E4E4E4`、深色 `#202020`，展开和收缩态共用 `sidebarActiveBackground`；头像继续保留 Bot 身份色。侧栏主体、收缩态和原生标题栏共用 `sidebarBackground`，用户与 Bot 消息共用 `messageBubbleBackground`。机器人详情面板与内容区同色，左侧用细分割线划清边界；弹窗、输入框和电脑面板继续沿用自身表面颜色。

配色及详情边界可通过 `flutter test test/theme_test.dart test/chat_bubbles_test.dart test/sidebar_colors_test.dart test/workbench_detail_surface_test.dart` 复验，覆盖双主题色值、气泡、桌面分栏、抽屉与手机详情，并验证切换和关闭面板保留聊天草稿。

## 交互复验

- 自绘操作图标使用圆端 SVG 描边。绘制尺寸为 16、24 或 32 时均保持 1.5 逻辑像素，搜索框的 48 像素点击区域也保留内部图形的尺寸。颜色、语义标签和方向跟随主题。
- 仅实时首次到达的消息在 220 毫秒内上移 8 像素并淡入。首次加载、翻页、重复推送和重连续传读取已有消息时直接显示正文。流式光标为 2×18，周期 1 秒；运行状态点周期 1.6 秒，等待审批时常亮。
- 变高消息长列表会在实测滚动范围变化后继续跟随到最新正文。用户向上阅读时保留当前位置，点击“有新消息 · 回到底部”可恢复跟随。
- 工具详情展开时箭头旋转 90 度。工作台详情栏收起时内容淡出，立即停止接收点击和键盘输入，恢复时保留草稿。待办在宽屏从右侧打开，手机从底部进入全屏。开启减少动态效果后取消位移、旋转和周期脉冲。
- 在工作台按 `⌘K` 或 `Ctrl+K`，或点击顶部搜索按钮，打开全局搜索模态框；按 Escape 或关闭按钮可继续当前会话。搜索覆盖 Bot、群组及例程会话、历史公开聊天正文与所有设置入口，不检索文件正文或 Bot 私有记忆。输入去抖 250 毫秒，历史结果每页 20 条，支持方向键、回车和前九项的数字快捷键；消息命中单独显示相邻上下文并突出命中项。新增选择框可用关闭按钮、Escape、返回或遮罩取消；选中类型后先关闭选择框，再叠加已有编辑页，背景聊天草稿保留。桌面用 Enter 发送、Shift+Enter 换行、Esc 中断活动回合。输入法正在组字时回车先交给输入法处理。

在客户端目录运行 `flutter test test/tom_icon_test.dart test/motion_test.dart test/chat_scroll_test.dart test/tool_result_test.dart test/approvals_test.dart test/workbench_test.dart test/identity_workbench_test.dart`，可复验不同窗口宽度、关闭中的命中区、草稿、工具展开、搜索以及减少动态效果。平台通知与深链另行验收。

## 桌面窗口

macOS、Linux、Windows 使用设备首选项记录主窗口的普通尺寸与位置。首次启动且没有记录时，默认尺寸为 1280×800 逻辑像素；已有记录继续恢复保存的尺寸与位置，不因升级覆盖。默认窗口与恢复窗口都按当前显示器的可用区域收敛。停止移动或缩放 200 毫秒后保存，最小尺寸为 390×640 逻辑像素，小屏按可用区域缩小下限。下次启动会选择与上次位置重叠最多的显示器；原显示器已断开时，窗口在主屏居中，菜单栏与任务栏所占区域不参与布局。最大化、最小化和全屏时沿用最后的普通窗口记录。

macOS 隐藏原生标题栏文字，Flutter 内容铺满整个窗口，红绿灯由系统继续绘制在左上角，左边距 20 像素、上边距 13 像素，相邻间距保持系统默认的 23 像素。每个原生按钮外叠加不响应鼠标或辅助功能的透明细圆环，按屏幕倍率绘制为一个物理像素，增强浅色背景下的圆形轮廓；不裁剪系统按钮的高光、悬停图标或阴影，也不更换关闭、最小化、全屏动作。圆环只在几何变化时更新位置。工作台内容从窗口顶部开始，左侧只覆盖高度 61 像素、宽度为 `max(侧栏实际宽度, 212)` 的局部工具条，承担拖拽与双击缩放；侧栏分割线贯穿窗口顶部。右侧 Bot 身份浮层顶部为 13 像素，群组标题沿用相同顶部内距，不保留全宽标题条。普通页面仍保留 48 像素标题条；全屏时隐藏自绘工具条。Linux 与 Windows 保留系统标题栏，安卓与 iOS 没有窗口标题栏。

非全屏 macOS 的搜索与新增按钮位于左侧局部工具条，均为 40×40 逻辑像素，上边距为 13 像素，与红绿灯的顶部齐平。按钮组横排并随侧栏实际动画宽度移动，左边界为 `max(侧栏宽度 − 96, 116)`；侧栏收缩到 100 时，搜索按钮从窗口横坐标 116 开始，与分割线保留 16 像素；右侧 Bot 身份浮层及群组标题为局部工具条预留横向安全区域，避免重叠。其他平台或全屏时仍放在侧栏内并使用原有会话标题布局。按钮区域不触发窗口拖拽，右侧会话操作不会被拖拽区域遮住。

连接流程的返回与主题按钮放在 macOS 标题条右侧，使用 40×40 逻辑像素点击区域，上边距 8 像素，中心距窗口顶部 28 像素，悬停和按下时的圆形底色完整留在窗口内。按钮区域不触发窗口拖拽或双击缩放；全屏、网页及其他平台使用页面右上角的按钮。标题条仍位于全局导航器之外，打开新路由后继续保留。此调整仅需更新客户端，无数据迁移；安装上一版客户端可回退。

在仓库根目录运行 `xcodebuild test -workspace client/macos/Runner.xcworkspace -scheme Runner -destination 'platform=macOS' -only-testing:RunnerTests`，可核对浅深色下的红绿灯位置、收缩侧栏留白、原生动作保留及圆环不拦截交互。

窗口恢复依赖随客户端分发的 `window_manager 0.5.2` 与 `screen_retriever 0.2.2`。移动端和网页跳过原生窗口调用。升级时保留已有有效窗口记录，无记录才采用 1280×800 的新默认值。损坏或无法读取的记录会显示重试和“使用当前窗口”；回退时退出客户端并安装旧版本，设备首选项不影响服务数据。窗口位置按设备保存，工作台分栏继续按服务器分别保存。

从客户端目录运行 `flutter test integration_test/window_placement_test.dart -d macos`，用独立的设备首选项位置验证首次默认窗口保存、真实窗口移动及重新打开后的读回，结束时还原测试窗口。显示器拔出、负坐标、小屏边界、全屏保护及写入超时后的顺序由 `test/window_placement_test.dart` 验证。

## 手机触控与间距

工作台、待办、浏览器、文件、群组、记忆、例程、终端、密钥及用量页在 390 逻辑像素宽度下检查可操作节点的 44×44 最小尺寸。浏览器地址、当前目录和审批详情的可复制短文本原先只有 16–40 像素高，现已扩展长按区域。单字 Markdown 链接可以从边缘点按；头像读取失败时，点击重试也有独立的命中区域。Bot 表单底部为系统手势区留出空间。

页面留白统一引用 `TomTokens` 的 4 像素倍数；控件、卡片和抽屉圆角分别为 10、14、20。变更后逐张对照桌面基线和手机、平板布局，核对文本换行、身份标线、表格、输入栏和栏间边界。手机的“会话”和“Bot”分别进入会话列表与 Bot 名录，“设置”与桌面侧栏的同名按钮打开统一设置模态框。

## 侧栏与统一设置

桌面和平板左侧栏默认宽度为 300，展开范围为 240–400 逻辑像素，收缩宽度为 100（红绿灯左右各留 20 像素），仅通过拖动右边缘调整，不再提供收起／展开按钮。计算宽度低于 170 即吸附到 100，达到 170 则至少展开到 240；跨阈值、取消拖拽及外部恢复使用 220 毫秒宽度动画，展开区连续拖拽直接跟手，减少动态模式下立即切换。拖动和动画中只预览，松手后串行保存，取消拖动不写入；读取或保存失败在工作台明确提示。

侧栏使用区别于右侧内容区的背景色，分割线延伸至窗口顶部。搜索和新增按上述平台规则放在局部工具条或侧栏内，二者与底部设置按钮均带圆形背景；新增弹窗提供“新增 Bot”“新增群组”，选中后打开对应编辑页。会话行展示圆头像、名称、实时更新的最新消息预览及未读标记，收缩后显示头像并通过悬停提示补充信息。展开和收缩状态下，普通 Bot 会话行均不显示更多图标；右键、触屏长按或聚焦后按 `Shift+F10`／菜单键打开私有记忆、Bot 设置和归档菜单，打开菜单不会切换会话或丢失聊天草稿。底部同一行放主机与端口、设置按钮，不再显示上方横向分割线；地址不含协议，保留域名，IPv6 主机使用方括号，过长时省略并保留完整提示，收缩后改为带提示的图标。桌面侧栏不再提供例程和待办；例程从“详情 → 管理例程”进入，待办可通过聊天 `/approvals`、例程页“审批待办”或手机底部“待办”进入。

设置弹窗在桌面采用左侧分类、右侧内容；手机采用横向分类，初始选中分类自动滚入可见区域。模型、用量与预算、密钥、设备与通知及已归档 Bot 均从设置进入，关闭后保留聊天草稿；切换分类或关闭前确认未保存的预算和审查配置，保存期间禁止离开，保存失败保留草稿。

默认助手 Tom 的常规直接会话在侧栏和空查询的搜索初始列表中置顶；输入关键词后按 Bot、会话及历史消息分类展示服务端匹配结果。例程会话初始列表仍按状态排序。默认身份使用稳定 Bot 标识判断，改名不改变身份，同名普通 Bot 不显示内置头像；Tom 未上传头像时使用随包图片，上传后优先显示上传图片，读取失败仍提供重试。首次无会话记录时进入 Tom，外部链接与已有会话记录优先；手机仍可返回会话列表。未配置模型时提供设置引导；Tom 的编辑、归档和删除行为与其他 Bot 相同。`test/default_assistant_test.dart` 覆盖身份识别、过滤排序与实时摘要更新后的身份保留。

主侧栏移除共享文件、终端、浏览器快捷入口。Bot 的“电脑”提供浏览器、终端与文件页签，文件支持 Bot 与共享范围；浏览器故障不影响文件编辑和终端使用。不再保留独立工作区入口；文件内的“在终端打开目录”会切到同一电脑内的终端。

侧栏尺寸与样式调整仅需更新客户端；全局搜索和 DeepSeek 自动获取模型需要同时更新服务端与客户端，接口与回滚说明见 [全局搜索](search.md) 和 [模型接入](provider-connect.md)，这两项不新增数据库迁移。每次完成侧栏调整增加一次本机布局保存，交互中不持续写盘。每个服务器的侧栏使用 `workbench.sidebar.v3.*`，只接受 100 或 240–400；旧 v1/v2 记录不读取、不改写，因此本次升级会将收缩及自定义展开偏好一次性重置为默认 300，之后正常恢复 v3 宽度。原会话与详情布局 `workbench.v1.*` 不变。旧设备主布局若指向已删除的 `workspace` 分区，会明确提示重置布局；点击重置后恢复默认布局，不影响会话与文件数据。

回滚旧客户端时仍读取保留的对应版本侧栏记录；v3 的 100 收缩宽度不回写 v2，不改变旧版偏好。若旧记录本身超出旧客户端的合法范围，按旧版提示重置。

运行 `flutter test test/resizable_sidebar_test.dart test/layout_preferences_test.dart test/workbench_sidebar_test.dart test/bot_context_menu_test.dart test/create_conversation_dialog_test.dart test/settings_modal_test.dart test/settings_visual_test.dart test/computer_pane_test.dart test/routines_test.dart test/approvals_test.dart`，可复核展开／收缩边界、170 吸附阈值、取消拖拽、旧记录隔离、恢复失败、实时预览、Bot 菜单、新增选择与防连点、草稿保护及资源和管理入口。桌面默认、最大、收缩侧栏和新增选择框由 `test/workbench_visual_test.dart` 比较像素基线。

原生工作台验收使用环回服务和一次性测试授权，从默认 Tom 的模型配置引导开始，验证自动绑定后的实际对话，再通过新增模态框创建三个 Bot，并从电脑入口检查文件与共享范围，核对四个 Bot 的服务端工作目录。在仓库根目录设置 `TOM_TEST_NATIVE_WORKBENCH=1`，运行 `go test -count=1 ./internal/httpapi -run '^TestNativeWorkbenchSetup$'`。macOS 默认使用桌面，iOS 模拟器和 Android 模拟器通过 `TOM_TEST_WORKBENCH_DEVICE` 选择设备。Android 还需要将 SDK 的 `platform-tools` 加入 PATH。端口转发只在用例执行期间生效。

## 冷启动与工作台恢复

应用首帧按宽度显示会话区域和桌面侧栏。读取本机安全存储、核验设备授权及读取布局期间只绘制占位，认证通过后才显示上次会话。空记录进入连接页；服务器不可达时显示网络错误并允许重连。

连接流程分为服务器地址、准备进度和密码三个页面。输入地址并连接后，服务器未就绪时进入准备页，已就绪时进入初始化密码或登录页。准备页和密码页右上角并排显示返回与主题切换按钮；返回后可修改地址并重新连接，未提交的密码和初始化码会清空，同一服务器的设备授权保留，切换服务器时隔离凭据。返回前在途请求与进度通知不能覆盖新页面。

云电脑准备页仅展示进度和必要的错误、修复入口。步骤优先通过实时事件更新；连续 5 秒没有步骤事件时，自动读取快照并从新游标继续订阅，读取串行执行。断流按 1、2、4 秒退避，之后每 15 秒重新查询；失败信息可见，修复与重置请求不会自动重发。执行中的步骤使用往返翻转的沙漏，完成后切换为结果图标，减少动态模式下保持静止。准备就绪后自动核验登录状态；准备失败时仍可返回地址页或进行修复。

此变更仅需重新构建客户端，无数据库迁移或接口变更。准备期间无事件时，每个客户端最多每 5 秒增加一次快照查询和实时订阅重建；离开页面会释放计时器与订阅，准备结束后停止该查询。会话保存串行执行，返回并登录另一服务器后，旧写入不能覆盖新凭据。回滚时安装上一版客户端即可。从客户端目录运行 `flutter test test/connect_progress_test.dart test/connect_session_save_test.dart test/bootstrap_maintenance_test.dart test/bootstrap_progress_test.dart`，验证窄屏布局、返回重连、凭据保存顺序、自动更新、失败恢复、动画及资源释放。
