## 规格冲突与实现决定

- 设计未指定月度预算与日期报表的时区，本实现固定为 UTC 自然月／日。预算使用实际调用账本，在新 Turn 的同一事务中检查；不预占费用或中断已接受回合。启用阈值和上限提醒时，每月每阶段仅保存一次；调整额度不会重复提醒，当前状态始终可在用量页查看。

- 例程的 `target_mode=new` 与初始 DDL 的 Bot／群组会话一一对应约束冲突。迁移 0012 将主会话唯一性限定为非例程来源，新增例程会话通过独立路由访问；主身份查询显式选择主会话。例程配置审批没有模型 Run，因此迁移保留原工具审批记录，并仅允许 `routine.create` 作为无 Run 审批。

- 初始化额外字段按测试策略与交付清单拒绝，覆盖第 12.2 节的“忽略”措辞；请求体仍只有密码，初始化码使用请求头。
- 官方浏览器分发格式为 zip，离线输入使用同一归档，避免二次打包导致摘要失去来源。
- 字体自检使用 CDP 返回的实际中文字形族并验证真实截图非空，不使用跨系统不稳定的 pHash 基线；缺字形会阻断 ready。后续视觉 golden 仍按文档只建立 macOS 基线。
- Chrome 不为 musl 提供当前锁定资产，Alpine 命令映射已有测试，但 glibc 不满足时明确失败，不能宣称全功能可用。
- 浏览器安装移到运行库验证之前，使 ldd 校验针对实际托管二进制，而非猜测系统包安装状态。
- chromedp 0.22.1 使用新的类型化 CDP 接口，需要 Go 1.25+；当前工程固定 Go 1.26.5。
- macOS 不需要跨应用共享凭据，使用插件支持的普通系统钥匙串；不启用需要共享组签名的能力。
- 普通动作审批仍受执行时限约束：若 Run 先达到时限，待办立即过期并取消工具；只有 Run 仍有效时，审批自身超时才回灌 `APPROVAL_TIMEOUT` 并继续循环。默认两者均为 30 分钟，因此较晚创建的审批通常先受 Run 时限约束。`ask_user` 单独使用 24 小时回答期限，人工等待暂停运行时预算；等待该子任务的祖先也暂停，仍在工作的父任务继续计时，详见会话工具文档。
- 独立审查先于严格度阈值判断，以便提升原本无需审批的风险；明确的 allow/deny 规则仍优先，浏览器点击／输入／按键按外发要求例外处理，即使 allow 也必须逐次询问。审查失败除提升一档风险外强制询问，避免 loose 模式下 low → medium 仍自动执行。自动独立性按 `model_key` 判定，别名不能证明底层模型不同。配置按工具调用读取，已生成审批保留原结果。
- 终端额外提供只读 `list` 动作，让 Bot 可发现用户为它创建的会话；用户接管后取消 Run 自动回收计时，交还后在下一次模型操作时绑定新 Run。采用版本校验阻止审批期间发生输入或接管后的旧动作。这里只管理同一 SID 的作业，不回收主动 `setsid` 脱离的守护进程。
- 浏览器底层串行执行命令，单次操作含排队最多 30 秒；全局最多 32 个标签、每归属最多 8 个。快照按 [CDP 无障碍树](https://chromedevtools.github.io/devtools-protocol/tot/Accessibility/#method-getFullAXTree) 构造，限制 300 行／32 KiB，不导出输入框 value；每次快照生成新的 ref，导航和交互都会使旧 ref 失效。恢复只重开地址，不重放点击或输入；连续失败最多三次，导航保护自身失败则需显式恢复。服务通过迁移 0008 保存标签，迁移 0009 保存来源许可，已接入模型域名与动作审批、实时画面和浏览器面板。归档根路径修正保留了真实根目录外链接的拒绝测试，无历史迁移修改。
- 浏览器标签按 ID 提供快照和截图接口，避免一个 Bot 多标签时选择含糊；页面动作同时提交控制版本和页面版本，关闭与交接提交控制版本。所有新增接口及迁移、锁顺序、超时、失败恢复和回滚方案见 [浏览器接口与恢复约定](browser.md)。HTTP 接口供鉴权用户使用，模型工具经过审批与来源许可检查。当前拦截范围是 Document 导航，不能宣称覆盖网页脚本 XHR、资源或 WebSocket 的全部外发；截图以文件产物返回，当前视觉模型也会收到原始 JPEG。

文件访问层增量验证：目录句柄隔离、符号链接越界、FIFO 与二进制拒绝、原子替换、审计失败不覆盖、并发编辑、纯 Go 搜索/匹配及共享路径回读均通过竞态测试。六项文件工具已接入模型执行器，按白名单、精确规则与严格度决定是否审批；审批支持超时、取消、重复决策保护和原子规则记忆。超长结果以分行 JSON 保存并支持窗口读取。
