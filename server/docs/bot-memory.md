# 猫咪长期记忆（当前 v2 执行链路）

当前桌面客户端通过 `execution` 调用容器 Bot Agent。原先的文件记忆、SQLite 索引与 v1 HTTP 接口没有接入这条链路，不能用旧模块的存在证明客户端已经具备长期记忆。本次新增 PostgreSQL 持久化和执行器内建记忆工具；每个用户、每只猫咪分别保存，默认招聘的猫咪无需重新创建。

## 日常使用

猫咪在正常对话和工作中，可以保存用户明确表达的长期喜好、工作习惯、工作方法和持续项目事实。例如“以后汇报先给结论，再列出验证结果”，会作为工作方法供之后使用。一次性任务不应存成习惯；从行为推测出的偏好要先向用户确认。是否调用工具和如何概括由对话模型判断，并非每句话都自动入库，也没有额外的后台总结模型调用。

可以直接对当前猫咪说“你记住了我哪些工作习惯”“把这个习惯改成……”“忘记这项偏好”或“忘记你的全部长期记忆”。操作成功后才能声称已保存、修改或遗忘；失败必须说明。没有新增设置页。遗忘清除活跃记忆中的正文，不会删除原聊天、既有运行快照、工具回执或备份，也不影响其他猫咪。

当前桌面创建的猫咪默认拥有工具能力，私人单聊会自动获得 `memory_search`、`memory_write`、`memory_delete`，无需客户端更新权限名单。工具由执行器保留，业务工具不能覆盖。禁用全部业务工具的纯文本机器人不启用此能力；群聊和机器人私信不开放私人记忆。服务端每次调用重新核验用户、猫咪、会话和运行租约，模型不能自行指定用户或猫咪标识。

## 保存、检索与一致性

- 记忆包含稳定主题键、分类、摘要、正文、版本和来源消息标识。分类为偏好、习惯、工作方法、项目。先搜索、再按版本修改同一主题，避免重复和覆盖较新内容。
- 来源必须是当前私人单聊回合中、已经传给模型的完整用户正文，证据片段必须匹配原话。模型提示词排除引用、文档、工具输出、表情和助手说法作为用户偏好来源，并要求不保存敏感标识或凭据。服务端校验来源归属及原文，语义是否属于持久偏好仍由模型判断。
- 主键为用户、猫咪、主题键；强制行级隔离保护租户边界。每只猫咪最多 256 个主题槽位，包含逐项遗忘后的删除标记。摘要最多 128 字节、正文 1024 字节、证据片段 256 字节。容量满明确失败，合并已有主题或由用户决定遗忘，不自动丢弃。
- 每次运行固定一份摘要快照，最多 8 KiB 且不超过运行上下文预算的四分之一。近期非项目偏好优先；超过预算明确标记还有更多记忆。完整内容使用中文或其他语言的字面关键词、主题键检索；空查询可分页浏览，每页最多四条。当前是有界关键词检索，不是向量语义搜索。
- 修改锁定猫咪行，串行执行容量检查、版本校验与遗忘水位。写入和成功工具回执在同一事务提交，恢复读取既有回执，不能重复应用。失效租约、冲突来源、版本冲突、数据库失败及结果超限都不能返回虚假成功。其他未知工具操作仍沿用原执行器的恢复屏障。
- 逐项遗忘保留主题键和版本并清空正文，以阻止旧来源复活该主题。全部遗忘释放所有槽位并提高猫咪的遗忘水位，旧来源也不能换键写回。更新习惯需要新的用户原话。恢复中的旧运行仍保留其固定快照，模型必须服从最新纠正和遗忘请求。

记忆说明、工具 schema、摘要、检索结果以及工具循环都会占用正常上下文、模型和工具步骤预算。保留原有按 UTF-8 字节保守估算路由容量的规则，不放宽限额；容量不足时明确失败。建议工具模型至少配置 16K 上下文，长历史或较多记忆应使用更大的真实模型容量，不能虚报模型规格。记忆仅在普通执行回合内维护，没有定时提炼、历史全量回填、跨猫咪共享或独立记忆管理界面。

## 升级与回退

新增迁移 `0068_bot_long_term_memory.sql`：创建空的 `bot_memories` 表，给猫咪增加遗忘水位，给运行增加可空记忆快照。不改历史迁移，不扫描或回填旧聊天，不移动旧 v1 文件。主键支持当前猫咪的有界检索；每次运行读取至多 256 个短摘要，不加载全部历史正文。

新增列需要短暂结构锁，通常不重写原表；执行时长受数据库锁竞争影响，沿用迁移锁等待、语句和事务时限。迁移错误整体回滚。先停接新任务、等待在途运行收尾、备份数据库，再执行 `tomd upgrade` 并部署服务端。提示词和用户消息来源标注会改变模型请求摘要，因此不能跨此次升级恢复未结束的旧版本运行。无需更新电脑镜像或桌面客户端。

旧程序不能直接启动已升级到 `0068` 的数据库。功能回退采用保留迁移账本的前向修复版本；结构修正只新增更高版本迁移。必须完整退回旧发布时，停单、保全升级后新增聊天和记忆，恢复升级前数据库备份及匹配程序。不得删除迁移记录或修改旧迁移来绕过版本检查。

验证包括真实 PostgreSQL 前向迁移、执行器与容器 Agent 协议回归、模拟模型工具循环、跨服务重建与历史截断检索、纠正和遗忘、来源校验、租户与猫咪隔离、分页容量和收尾失败后的恢复。模拟模型测试验证链路，不代表所有真实模型都会稳定、准确地提炼习惯。
