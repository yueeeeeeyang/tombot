# 自定义猫咪与直接交付

招聘页可在预设猫咪和自定义猫咪之间切换。自定义猫咪需要上传头像，可填写最多 120 个 UTF-16 单位的初始介绍。桌面接受最大 4 MiB、长宽不超过 4096 像素的 PNG、JPEG、WebP，居中裁成 128 × 128 PNG。服务端只接受不超过 96 KiB 的 PNG 数据地址，完整解码并重新编码去掉元数据；不接受远程地址或 SVG。群头像仍使用建群时最初四位成员的图片快照。

用户填写的自定义介绍作为猫咪的初始角色偏好进入上下文，后续工作习惯通过实际对话与记忆完善。详情页展示的 AI 介绍仍由记忆单独总结，不回写角色设定。预设猫咪不恢复原来的一句话介绍字段。

## 私聊职责与结果归属

message_bot 新增可选布尔参数 deliver_to_user。用户要求另一只猫咪执行并直接给自己结果时，发送者应先转交原始任务，设置该参数为 true，不先自己完成工作再让对方转述。子执行继续使用接收者自己的模型、角色、工具权限、私有工作区和记忆；不会继承发送者的私有提示或工具历史。

接收者成功完成后，服务将它的最终正文及附件原样写入它与用户的单聊，保留实际 bot_id 和 run_id。父调用仅得到 delivered_to_user 回执，避免发送者重复总结或冒领。失败、取消、超时、空结果或投递失败不报告交付成功。投递之前检查活动运行，并在事务中写入消息、审计与事件；自动交付使用运行唯一消息标识，重复处理不生成重复内容。已发出的内容不会因父回合稍后失败而撤销。

message_user 是直接联系真实用户的工具，只有 message 参数，无 Bot 收件人。它在当前猫咪自己的单聊中发布内容，不创建子执行，不受祖先 Bot 往返限制；用户与名叫 Tom 的 Bot 始终是不同对象。正文限制为 10000 个 UTF-16 单位及 32768 个 UTF-8 字节，超长结果应保存在共享文件中并发送摘要。工具动作分类为 message.user、低风险，仍经过工具白名单和统一审批策略；活动工具调用 ID、运行 ID 与发言身份必须匹配。同一个工具调用重复投递幂等。接收者显式调用了 message_user 时，自动交付不会再发一次。

handoff.created 和新增 user.message 事件在提交后立即通知桌面。父事件流只转发该回合及其有界后代的投递事件，不混入其他会话。桌面读取已保存的通知和结果，按消息 ID 合并到双方会话，保留用户草稿与当前选择，不把收到的通知另造一条写回服务。私信旁观窗口打开期间每 1.5 秒顺序刷新，关闭即停止，失败会提示并停止轮询。群聊与私信统一使用服务端返回的时间正序。

## 工作动画与实际执行

界面只有空闲和工作中，不增加“等待回复”状态。动画由实际运行事件驱动，不由 HTTP 请求是否结束驱动。调用方把任务交出并释放执行槽后立即停止动画；接收方开始执行时显示自己的动画和模型工作摘要。只有调用方收到结果或失败回执、重新取得执行槽并继续处理时才恢复动画。不要求回复的投递在收尾期间保持空闲，接收方完成不会让发送方再次工作。

服务流新增 activity 事件，携带 run_id、bot_id、is_working、is_finished；process 事件也携带运行和猫咪标识。子任务的活动和公开工作摘要可以流入发起回合，子任务的回复正文仍留在自己的会话。桌面按请求和运行分别记录活动，处理结束标记、重复事件和迟到摘要；流结束或断线只清理所属运行，避免熄灭同一猫咪的其他执行。群聊也只展示实际执行成员。请求在后台收尾期间仍保留原来的重复投递保护，不显示额外的等待状态。

这部分不新增数据库状态或迁移；已有任务预算、取消、子任务收尾与费用归集规则保持不变。需配套更新服务端与桌面端；回退时两端一起回退这部分代码即可。回归测试覆盖交付、独立执行、回执恢复、无需回复、失败和取消；Electron 使用可控执行关卡验证两只猫咪的动画交接。

## 文件粘贴

聊天与群聊输入区接受粘贴的图片、文件对象和系统文件引用，并复用现有附件上传接口。系统文件仅从剪贴板明确标记的本地文件格式读取，不把普通文字路径变成文件访问；拒绝网络文件地址、目录和符号链接。单条消息最多四个附件，单次添加总量不超过 32 MiB；正在上传时阻止并发添加和发送，失败保留此前成功上传的附件。普通文字与网页链接继续按文本粘贴。

## 升级、性能与回滚

新增迁移 0028_custom_cat_profiles.sql，为 bots 添加 custom_avatar，并为已有桌面猫咪的工具白名单加入一次 message_user。历史迁移未改动，已有头像品种、介绍、消息和记忆不变。迁移扫描桌面 Bot 的工具配置并持有 SQLite 写锁，耗时随 Bot 数量增加；没有逐消息回填或外部调用。头像受单张及工作空间整体大小限制，每次快照会增加图片编码的传输量。投递事件使用按主键回溯、有深度上限的祖先查询；仍沿用原来的子任务数量、四跳、时限与预算限制。

升级前停止活动回合，备份数据库及完整工作区，先升级服务端再配套更新桌面端。旧二进制不能打开版本 28 数据库。完整回滚须先保全升级后的内容，停服务后恢复升级前数据库、工作区及配套二进制；不得删除新列、改迁移账本或只退回二进制。重启继续沿用中断恢复，不自动重放已发送的任务或结果。

回归测试使用可控模型，但执行真实工具和数据库路径：确认目标猫咪读取自己的文件、结果先于发送者完成到达用户、目标失败不冒报交付、用户通道不联系 Tom、不生成子任务、重复调用去重、拒绝冒充身份，以及通知过滤、头像校验和旧库迁移。Electron 用例验证真实头像裁剪保存、剪贴板文件上传和消息顺序；外部商业模型是否正确选择工具仍需在对应模型配置下验收。
