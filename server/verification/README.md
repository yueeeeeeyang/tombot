# 并行桌面共享浏览器验证

`make test-shared-browser` 验证用户级共享浏览器服务所需的基础能力。它启动单一 Chromium 持久配置和本地测试站点，实际建立两个不同窗口及页面，通过各自 CDP 会话并发发送鼠标和文本输入，并确认内容不串目标。每个页面启用焦点模拟，不能依赖一个全局活动窗口轮流获得键盘焦点。

同一测试还验证共享 HttpOnly Cookie、登录、退出、账号切换、`localStorage`、IndexedDB、关闭单个窗口不影响另一个窗口，以及重启后配置持久化。测试使用独立临时 profile，不读取已有浏览器、Cookie 或账号，也不访问外部网站。网页中的账号仅为本地测试状态。

浏览器窗口尺寸与页面视口分别设置并检查。新建窗口必须容纳实际渲染视口，不能只放大截取区域；本次已修正窗口高度小于页面视口时出现的截图重复区域，并复核两张最终截图。

依赖来自已有 `admin` 开发环境中的 Playwright。执行前安装管理端依赖，并显式指定 Chromium 二进制和本次专用的报告目录；缺少配置直接失败，不跳过：

```sh
TOM_TEST_BROWSER_BINARY=/绝对路径/Chromium \
TOM_TEST_BROWSER_REPORT_DIR=/本次专用临时目录/浏览器验证 \
make test-shared-browser
```

本次使用 Chromium 158 完成验证，两张窗口截图已复核。该测试证明共享 profile 下的窗口并发和站点状态共享，不证明两个 Linux 图形桌面、窗口客户端、桌面鉴权、跨 Bot 越权防护、Linux 浏览器沙箱或整机故障恢复已经实现。完整交付仍须将同样交互放入两个真实 Linux 桌面，并验证截图、输入和窗口归属。
