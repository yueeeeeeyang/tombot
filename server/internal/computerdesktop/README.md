# 机器人桌面身份

本模块把每个机器人固定绑定到其用户电脑内的一个逻辑桌面。创建机器人、登记桌面、建立单聊、更新工作空间及写入事件共同提交，任一步失败都会回滚。桌面登记只建立归属和运行身份；图形会话由执行控制层按需启动。

## 身份和共享边界

| 字段 | 规则 |
| --- | --- |
| `user_id`、`computer_id` | 同一用户所有机器人绑定同一台电脑，不同用户使用不同容器 |
| `bot_id`、`desktop_id` | 每个机器人只有一个稳定桌面，桌面也只能属于该机器人 |
| `display_number` | 在用户电脑内单调分配 1–4095，与镜像启动器的范围一致 |
| `linux_uid` | `100000 + display_number`；保护各自桌面的认证目录、画面和输入 |
| `shared_gid` | 同一用户容器内固定为 20000，赋予各机器人共同读写业务文件的权限 |

这些数字属于镜像与服务端协议保留范围，定义见 [DesktopIdentity](../computer/desktop.go)。不同用户容器可以使用相同数值身份；文件隔离由独立容器和用户卷保证。桌面 UID 不用于强制隔离业务目录。显示编号容量是可登记的总量，并不表示容器可以同时运行 4095 个桌面；运行并发还须受资源额度控制。

身份在归档、恢复和容器实例重建后保持不变。记录及编号不删除、不回收，避免旧桌面目录、文件归属和迟到消息被解释为其他机器人。电脑实例代次、桌面控制代次和运行状态由执行协议管理，不能由稳定身份推断。

## 事务与接口

`Register` 接受已鉴权的租户事务及服务端生成的用户、机器人、桌面 ID。调用方先插入机器人，随后登记桌面；双方的延迟复合外键在事务结束时检查完整绑定，禁止单独提交无桌面的机器人或无机器人的桌面。

分配器使用不指定冲突目标的 `ON CONFLICT DO NOTHING` 创建用户分配记录，覆盖主键和复合唯一索引的预期并发冲突；随后锁定 `desktop_identity_heads` 的用户行并复验电脑归属，检查相同身份是否已经登记，再推进编号并写入桌面。该冲突处理范围遵循 [PostgreSQL INSERT 文档](https://www.postgresql.org/docs/16/sql-insert.html)，不忽略外键、检查约束或身份不符。相同身份重试不消耗编号。创建接口的幂等键仍由机器人目录处理；编号分配锁不能用于图形执行互斥，也不跨节点调用持有。数据库连接沿用调用方配置的语句、锁等待和事务期限，失败向上返回，不自行重试事务。

`Lookup` 只在当前用户的 RLS 范围内读取。业务 API 仅返回 `desktop_id`，不允许请求指定 Linux UID、公共 GID、显示编号或桌面 ID。读取身份不会获得截图、输入或终端权限；执行入口仍须复验用户、电脑实例、桌面归属、有效租约及控制代次。

## 数据结构与发布

新增迁移 [0041_bot_desktop_identities.sql](../store/postgres/migrations/0041_bot_desktop_identities.sql)，此前迁移保持不变。`bot_desktops` 与 `desktop_identity_heads` 均强制 RLS；租户只能新增和读取身份、推进编号，控制角色只读，调度和认证角色没有新增表权限。数据库约束及触发器阻止身份改写、归属替换、编号倒退和记录删除。

按不兼容旧数据的目标，本迁移只接受空机器人目录，不自动补造旧桌面身份，也不删除现有记录。旧 PostgreSQL 中间模型已有机器人时迁移明确失败并整体回滚；正式启用从全新空 PostgreSQL 库初始化。迁移会取得机器人表结构锁并建立索引和外键，应在停写后执行；不扫描转换旧业务数据，锁等待和执行时限由迁移器限制。

机器人接口新增必需响应字段 `desktop_id`，内部机器人创建必须同事务登记桌面。部署必须使用理解新模型的服务版本；应用回滚需先停止目录写入，保留身份、分配记录及版本账本，恢复到与该结构匹配的版本。不能通过删表、清空编号或恢复到没有桌面登记的创建路径实现回滚。

## 验证与接入进度

真实 PostgreSQL 测试覆盖独立并发分配、创建幂等、跨用户读写拒绝、缺失与盗用桌面、归档恢复、容器换代、编号耗尽、事件失败及锁等待取消的回滚。迁移测试覆盖空目录前向升级、重复执行和已有机器人时保留全部原数据。HTTPS 联合测试验证创建和重试返回稳定桌面 ID，并拒绝客户端注入运行身份。

```sh
go test -race ./internal/computer ./internal/computerdesktop ./internal/bots ./internal/store/postgres ./internal/userapi
```

当前已接入机器人目录、v2 用户 API 和 `computercontrol` 的桌面会话身份绑定。控制面已通过 `0042` 改为桌面独占与用户并发额度；节点会话记录和容器代理仍需从整台电脑独占改为按桌面控制；共享浏览器窗口网关及真实桌面生命周期也未接入主入口。登记身份通过测试不代表这些执行链路已支持多桌面并行。
