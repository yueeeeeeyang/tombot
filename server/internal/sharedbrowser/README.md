# 用户共享浏览器内核

本模块通过私有 CDP 管道接管用户电脑中的一个 Chrome 实例。所有窗口使用同一常规浏览器上下文，共享 Cookie、localStorage 和 IndexedDB；窗口归属于完整 Bot 执行会话。它不启动宿主浏览器，不开放网络调试端口，也不将全局 CDP 能力交给 Bot。

当前已实现页面创建、归属查询、页面截图、导航、有限键鼠动作、页面对话框、弹窗归属及定向关闭。受管启动、profile 独占与持久监督已接入[正式电脑代理](../computeragent/README.md#共享浏览器监督与控制协议)，宿主服务生命周期已接入节点，会话入口已接入代理资源回收。用户最新要求直接使用原生 Chrome，自研 GTK 窗口客户端及依赖已移除。本模块目前驱动无头 Chrome；它提供自动化基础，不能替代后续原生应用远程桌面。下载仍禁用，上传与联合能力探针未完成；Agent 本地工具已接入，真实生产宿主组合仍待验收。

## 调用边界

`New` 接收 Chrome 的响应读端和命令写端，初始化成功后接管两端寿命；启动失败关闭管道。参数校验失败时尚未接管描述符，由调用方回收。Chrome 必须由受信监督器以专属非 root 身份启动，使用私有持久 profile、原生沙箱、独立用户级资源组及受控出网代理。停止单个 Bot 不得结束该共享进程。

持久目录已由节点和镜像布局 2 准备：同一用户磁盘的 `browser` 子目录单独挂载到 `/var/lib/tombot-browser`，属于服务 UID 30000、公共 GID 20000，权限 0700。业务目录仍为全 Bot 共享的 `/workspace`；Bot 通过同一浏览器上下文共享账号状态，不直接读取或改写 profile。代理取得 profile 独占锁，明确消费授权后启动 Chrome；目录、权限、实际 Docker 子路径及重建保留证据不能替代尚未完成的浏览器联合能力探针。

`Options` 显式指定用户、电脑及实例代次，授权回调每次复验完整执行会话，包括控制代次、当前租约与撤销。窗口只接受平台分配的 ULID，接口不接受 target ID、CDP session ID、显示编号、BrowserContext 或任意调试地址。授权回调必须遵守传入的截止时间。

| 限制 | 范围与行为 |
| --- | --- |
| 页面视口 | 宽 320–1280、高 240–800；不是对外 Linux 桌面的尺寸配置 |
| 活动窗口 | 每用户 1–128、每执行会话 1–32，且不超过用户窗口额度 |
| 窗口回执记录 | 不少于活动窗口额度，最多 4096；已关闭记录保留到会话回收，满额明确拒绝创建 |
| 事件队列 | 16–4096 项；归属事件溢出后停止整个共享服务 |
| 单次调用 | 100 毫秒–30 秒，等待窗口门禁计入时限 |
| 会话与服务关闭 | 1–60 秒；不能确认页面消失时停止共享服务 |
| CDP 帧与命令 | 响应帧最大 8 MiB，命令最大 256 KiB；超限与短写均明确失败 |
| 截图 | 真实 PNG，最大 4 MiB，校验完整解码及固定视口尺寸 |

启动时清除无主页面，将内部控制页面导航至空白页，不恢复旧运行的页面执行。常规上下文与持久站点状态仍由 Chrome 保留；不会复制 Cookie 或为每个 Bot 创建隔离上下文。

## 并发、回执与关闭

每个窗口有自己的操作门禁。创建和弹窗登记只短暂使用创建门禁；一个页面的慢导航、输入或截图不占用其他窗口的操作门禁。列表返回当前会话所属窗口；同用户的其他 Bot、错误实例代次及同 Bot 的旧执行身份均拒绝访问。

窗口列表每次使用一次有界 `Target.getTargets` 查询获取当前标题与地址，返回前重新核对完整授权，再按已有窗口归属过滤。真实 Chrome 回归发现目标事件可能保留导航前标题，因此不能只读事件缓存。查询失败、取消、撤销、缺失或异常目标都明确失败；并发已关闭的窗口不会被快照重新加入。此调用增加每次列表一次本机 CDP 往返，不随窗口数量产生 N+1 查询，也不向客户端暴露其他 Bot 或原始 target 标识。[Chrome 目标查询协议](https://chromedevtools.github.io/devtools-protocol/tot/Target/#method-getTargets)

`Execute` 要求正递增序号，允许序号空隙。相同末次命令只返回当前回执；替换内容、旧序号或未知结果不发送到 Chrome。`command_state` 区分 `running`、`waiting_dialog`、`completed`、`navigation_failed` 和 `unknown`；尚未执行动作的窗口为空值。等待对话框表示动作已开始但尚未完成，不能把 HTTP 成功当作网页业务完成。在途动作拒绝新动作，列表仍可查询，另一个 Bot 不受阻塞。

`RespondDialog` 使用窗口内独立序号与门禁，处理 alert、confirm、prompt 和 beforeunload。Chrome 可能在对话框关闭前不确认原输入；此时 `Execute` 先返回包含原动作序号和对话框的 `waiting_dialog`，允许顺序 Agent 在下一步答复，之后查询 `completed`。重复末次答复复用结果，旧对话框、不同答复内容及跨 Bot 答复拒绝；未确认答复不重发。对话框文本只返回所属窗口，不写日志。

实际执行与等待对话框分别累计预算。`DialogTimeout` 必填，范围为 1 秒至 10 分钟；节点通过 `browser.limits.dialog_timeout_ms` 下发，部署示例为 300000 毫秒。同一动作的多个对话框共享等待额度，答复后只恢复尚未消耗的执行预算。等待回执返回后不再受已结束的单次请求控制，仍受窗口寿命、租约撤销与等待预算约束。超时进入 `unknown`，不得继续答复或重放；关闭窗口、撤销会话和停止共享服务均取消并等待在途动作退出。

弹窗按 Chrome 的 opener 继承完整会话；没有已知父窗口或授权已结束的页面被关闭。容量不足时关闭新弹窗，并在父窗口返回中文提示与记录不含页面内容的警告日志。关闭页面须通过 Chrome 查询确认已经消失，不能只依据关闭命令回包。页面自行关闭与重复关闭都可确认原结果；迟到的创建请求不能复活已关闭窗口。

监督器应先撤销会话授权，再调用 `ReleaseSession`，等待该会话的页面确认关闭后回收桌面及任务资源。回收清除该会话的窗口回执，其他会话及共享登录态继续保留。创建、归属事件、页面关闭或管道状态无法确认时，`Done` 关闭并撤销整个共享服务；上层须报告共享能力故障并确认 Chrome 资源组退出，不能自动重放网页动作。

## 每桌面的窗口入口

`NewGateway` 固定一个完整执行会话；`Serve` 只接收 Linux Unix 流监听器。接受连接时读取 `SO_PEERCRED`，只允许该 Bot 的 UID 与公共 GID；每次请求调用必填 `PeerCheck`，复验实际 PID 所属执行资源组、当前控制代次、租约与撤销状态。请求 JSON 和 HTTP 头不能提供或替换用户、Bot、会话、UID、显示编号或 CDP 标识。

监督器在所属桌面的私有路径建立 root 持有的 socket，通过目录权限和受控组权限允许本桌面访问，并保持 socket 的设备号与 inode。入口关闭不会按路径自动删除 socket，避免误删后来替换的文件；监督器验证原身份后清理。调用方必须核对服务端内核身份，不能仅凭用户可写目录中的文件名信任服务。路径创建、生产 cgroup 检查、会话撤销与页面回收已由[代理窗口监督](../computeragent/README.md#会话窗口入口与回收)组合；目前入口仍限定所属 `browser` 子组，自研窗口客户端已删除，Agent 直接工具调用的接线和身份链尚未完成。

接口采用 Unix socket 上的 HTTP/1.1，固定 Host 为 `browser.local`，版本 2；旧 `/v1` 路由直接拒绝。拒绝其他 Host、绝对代理 URL、查询参数、来源头、升级协议和无效 JSON。所有响应均禁止缓存，错误只返回固定中文说明与错误码，不回传底层协议或页面内容。每请求使用独立连接，不自动重试网页副作用。

| 方法与路径 | 行为 |
| --- | --- |
| `GET /v2/state` | 协议版本、视口尺寸和本会话窗口；窗口包含末次操作序号，供客户端重新连接后核对 |
| `PUT /v2/windows/{id}` | 使用客户端预先生成的稳定 ULID 创建空白页面，请求体为 `{}` |
| `POST /v2/windows/{id}/command` | 发送受限 `Command`，沿用窗口内序号与未知结果规则 |
| `POST /v2/windows/{id}/dialog` | 答复本窗口指定序号的页面对话框 |
| `GET /v2/windows/{id}/image` | 返回所属页面当前 PNG；错误使用 JSON 与对应状态码 |
| `DELETE /v2/windows/{id}` | 确认所属页面关闭，重复关闭复用已知状态 |

状态码区分参数错误（400）、授权失效（403）、冲突/未知/在途动作/等待对话框（409）、导航失败（422）、容量不足（429）和服务不可用（503）。客户端必须根据 `code` 区分 `unknown` 与普通 `conflict`，未知操作不能通过递增序号重新发送。

`GatewayOptions` 显式限制连接数 2–16、每次调用及请求头/读写期限 1–30 秒、退出等待 1–60 秒。最少两个连接允许触发页面动作与对话框答复并行。超限连接立即关闭，未完成请求头的连接到期释放；请求体最多 32 KiB。停止接单先标记关闭并取消请求上下文，再关闭全部连接，等待在途业务处理退出；超时明确失败，不能报告干净退出。

## 验证与部署

普通单元与竞态测试：

```sh
go test -race ./internal/sharedbrowser
```

真实 Chrome 测试使用 `browserintegration` 构建标签，只允许在专用 Linux 临时容器中执行，要求 root 测试入口及 `TOM_SHARED_BROWSER_TEST=1`。Chrome 子进程降为独立非 root 身份，保留原生沙箱，只用私有调试管道。可通过 `TOM_SHARED_BROWSER_REPORT` 指定此次测试的画面与沙箱报告目录。

测试容器必须使用专用电脑镜像及其 seccomp，禁网、只读根目录、不可提权和有限资源，不挂载 Docker socket、宿主 cgroup 或已有用户卷。测试 HTTP 站点只监听容器内部。Linux 竞态测试使用镜像内 Go/gcc，源代码和模块缓存只读，构建产物写入独立临时目录。

已验证两 Bot 并发中文输入、独立截图、跨 Bot 拒绝、页面对话框、弹窗继承、慢页面并行、关闭重放保护、未知操作不重发、共享登录/退出/账号切换、Cookie/localStorage/IndexedDB 在正常重启后保留，以及实际 Chrome 命名空间与 Seccomp 沙箱。故障测试覆盖浏览器异常退出、启动超时、事件溢出和回执容量。测试启动器没有生产 cgroup 入组逻辑，不能替代进程监督、出网网关与原生应用远程桌面的联合验收。

窗口入口测试通过真实跨 UID 进程请求、Chrome PNG、全部协议路由、身份字段注入拒绝、错误内容隐藏、授权撤销、连接容量、请求头期限、关闭等待与替换路径保留。集成测试在容器根 cgroup 核对真实对端；生产仍必须核对每次执行的独立子组。原生 Chrome 多桌面展示随远程电脑另行设计，不再补自研 GTK 窗口。

本模块没有新增数据库迁移，已被正式代理入口引用并编入本地镜像；代理新增三个浏览器控制动作、版本 1 的持久浏览器记录，部署配置升级为版本 4。后续生产接入必须将节点、电脑代理、服务资源组与镜像一起发布；回滚先停止接单并排空全部浏览器会话，确认共享进程退出并保留完整控制记录后再更换匹配组件，不允许旧代理忽略新记录或两个 Chrome 实例同时写同一 profile。当前仅完成本地验证，尚未切换生产。

## 容器内 Agent 客户端

`NewClient` 只接收完整执行会话，没有任意连接地址。Linux 客户端校验实际 UID/GID、根目录和会话目录权限、root 所属 socket，并通过 `SO_PEERCRED` 核验服务对端。目录以描述符固定，拒绝符号链接；不使用环境代理，不跟随重定向，不复用连接或重试动作。响应有界读取并核对窗口归属、协议版本和状态。

正式窗口网关只允许当前会话 Agent 所在的 `shell` 子组；同 Bot 当前运行的工具进程拥有同一页面能力，其他 Bot、旧运行和其他资源组均拒绝。此调整取代已取消的自研窗口客户端 `browser` 子组入口，不扩展宿主控制协议。

导航回执后 Chrome 可能短暂返回 `Not attached to an active page`。截图仅对这一明确 CDP 错误重新取只读画面，最多五次，退避为 25、50、100、200 毫秒，同时受原调用期限及每次授权复验约束。其他故障不重试，取消、撤销、窗口关闭立即中止；不会重发导航、点击或输入。真实客户端回归覆盖导航后立即截图，另有虚拟时间测试验证次数、退避与撤销。
