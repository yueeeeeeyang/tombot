# 容器电脑工具

本模块把 `computer_shell`、`computer_screenshot`、`computer_input` 交给已授权电脑的终端和桌面运行器。[执行适配](../execution/README.md) 实现 `execution.Tool`，再次核对用户、Bot 和运行归属。[应用组合](../serverapp/README.md) 从同一注册集合生成工具定义和 Bot 权限目录；不接受模型传入容器 ID、UID、DISPLAY、环境变量或节点地址。`computer_browser` 使用下述 Agent 本地执行器；文件和交互终端工具仍待接入。

## 命令与共享目录

参数为必需的 `command`、可选的 `cwd` 和 `timeout_seconds`。命令上限 4096 UTF-8 字节；工作目录默认 `/workspace`，相对路径从该目录解析。其他绝对容器路径按当前 Bot 的普通文件权限访问，业务文件不做 Bot 级路径隔离。重复字段、未知字段、大小写别名、空值、NUL 和越界参数在节点调用前被拒绝。

实际程序固定为 `/bin/bash --noprofile --norc -c`，命令作为单独参数传递；节点通过既有任务引导执行入组、降权及环境配置。每个 Bot 保留自己的 UID、桌面环境和终端；公共 GID 用于用户共享业务目录及工具。Shell 的标准输出和错误输出合并为 PTY 输出，不适合交互输入或二进制传输。

沿用当前 `policy.NeedsApproval` 的行为：三种有效模式均不等待审批；未知模式拒绝执行。现有特权命令分类仍默认拒绝，模式识别不作为权限隔离边界；实际权限由容器、非 root 身份、受保护图形目录和任务引导保证。此改动没有恢复旧审批弹窗，也没有改变现有策略规则。

## 有界执行与结果

`ShellOptions` 必须显式配置每次节点调用期限（100 毫秒至 10 秒）、无新输出时的轮询间隔（10 毫秒至 1 秒）及结果容量（1–24 KiB）。`MaximumResultBytes` 必须不大于 Worker 的 `MaxOutputBytes`。命令期限默认 120 秒、可指定 1–600 秒，始终同时受 Worker 工具及运行期限约束。

Worker 先以 `computer` 类型记账并绑定电脑会话，再把该操作 ID 用作终端启动 ID。启动只发送一次，后续读取携带完整桌面授权和单调输出游标；不重试未知启动或读取。终端协议和工具共用输出校验，拒绝倒退、无标志缺口、截断标志掩盖的游标重叠、无进度尾部、无效编码及退出状态。

正常结果为 JSON 文本，含 `output`、`exit_code`、`truncated`。输出保留有界 UTF-8 尾部，容量计算包含 JSON 转义；不会为了控制字节膨胀而把有效尾部全部删除。直接程序退出后仍须读完已有输出。已知非零退出作为工具错误回灌 Agent，允许 Agent 判断下一步。

总期限、通信、输出读取或退出等待失败不能证明命令未产生效果：工具返回基础设施错误，Worker 保存未知操作、终止该运行并按其授权清理。直接 Shell 退出不证明后台后代已结束；它们仍属于原运行，最终由执行会话整体回收。该工具没有提供交互终端保活或局部进程树清理接口。

## 桌面观察与输入

`computer_screenshot` 只接受空对象，启动或复验所属桌面后，取得完整 1280×800 PNG。每块最多 32 KiB，全部块的身份、尺寸、长度和摘要必须一致；装配后验证 SHA-256 与实际 PNG 解码。模型图片最多 4 MiB。图片先由服务端原子持久化，Agent 只收到引用；实际模型请求装配见[执行模块](../execution/README.md#截图持久化与模型视觉)。

`computer_input` 提供点击、双击、移动、拖动、滚动、文字和组合键。坐标固定在 1280×800 内；文字最多 256 个字符，组合键最多 8 个，滚动最多 20 次。拒绝重复、无关、空值和非法字段，整批释放按钮与按键。中文转为 X11 Unicode keysym，不使用共享剪贴板；普通控制字符拒绝，换行和制表符按对应按键发送。

两个工具都要求模型支持视觉和工具调用。`DesktopOptions` 显式限定单次节点调用、状态轮询和桌面启动期限；应用默认启动等待 45 秒。启动只发送一次，随后有界查询就绪状态。持久操作序号递增但允许空隙，模型步骤或拒绝参数也会占号；不能由模型自定序号。`sent` 仅确认输入发送，应用处理可能滞后，应再截图观察。未知输入立即终止运行，不自动重发。

## 验证与部署

单元测试覆盖参数、策略、归属、游标、有界中文与控制字符输出、取消、期限以及不重发。真实 PostgreSQL Worker 测试覆盖先记账后调用、电脑会话外键、已知失败回灌、未知终态及释放。Linux `agentintegration` 测试使用两个真实 Bot Agent 和非 root PTY，同时写入及读取共享文件，并验证独立 UID、DISPLAY 和完整模型—工具—模型循环。

Linux 测试的终端启动器仅在测试中直接降权；固定生产引导和真实业务 cgroup 入组、整树回收、节点与主入口联合验收仍待完成。模型响应使用受控测试实现，不请求公网模型。

桌面测试另覆盖真实 PNG、多块读取、损坏内容、参数边界、中文、启动取消和未知输入。真实 PostgreSQL 测试验证操作先记账、原子存图、用户及运行归属、并发额度、最近图片装配和已结束任务的有界清理。受限 Linux 测试使用两个真实 Agent 及 XFCE 桌面并行完成截图、中文输入、再次截图的循环；模型响应仍是测试中继。

截图持久化新增迁移 `0043`，此前历史迁移不变。Worker、节点及镜像须成套发布；序号契约和 Agent 引用字段不兼容旧活动连接。回滚先停单排空，保留已知及未知操作、桌面关闭屏障和卷，不通过更换操作 ID 重放未知动作，不回退到宿主执行。数据库锁影响与回滚要求见执行模块。

## Agent 本地浏览器

`BrowserSchema` 同时供服务端目录与 Agent 使用。`cmd/bot-agent` 注册 `NewBrowser`，收到授权后固定完整执行会话，通过 `sharedbrowser.Client` 连接所属 `/run/bot-desktops/<session_id>/browser.sock`，没有节点运行器、TCP 调试地址或服务端浏览器执行路径。

工具支持分页列举、创建、检查、导航、返回/前进/刷新、点击、双击、移动、滚动、输入、组合键、截图、对话框答复和关闭。序号与创建标识来自已登记操作；模型不能指定用户、电脑、CDP target 或浏览器上下文。参数拒绝重复键、别名、null 和动作无关字段。页面字段为不可信内容；输出截断明确列出字段，窗口列表在最小输出额度下也能分页取完。

仅对当前会话所属页面执行。用户所有 Bot 共享 Chrome 的常规上下文和站点状态；文件系统仍共享。正常参数拒绝和可确认的页面忙碌回灌模型，连接失败、授权失效和未知动作中止运行，不重发副作用。等待对话框后需答复并检查动作完成；`Finish` 拒绝将遗留的等待、在途或未知页面报告为成功。上传下载尚未接入，原生桌面呈现另行设计。
