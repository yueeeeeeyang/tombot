# 猫咪预设头像

由 OpenAI 内置 `imagegen` 逐张生成，未使用 CLI。PNG 原图随应用打包，保留透明背景和描边，在深浅主题中不反色。完整生成提示词保存在同目录的 [prompts.json](./prompts.json)；每条提示词对应同名 PNG 文件。

| 文件                   | 预设名称   | 区分特征                       |
| ---------------------- | ---------- | ------------------------------ |
| bombay.png             | 孟买猫     | 黑色短毛、琥珀色眼睛           |
| orange-tabby.png       | 橘猫       | 姜黄色、额头虎斑纹、奶油色嘴部 |
| british-shorthair.png  | 英短蓝猫   | 蓝灰色、圆脸、铜色眼睛         |
| ragdoll.png            | 布偶猫     | 长毛、白色倒 V 脸纹、蓝色眼睛  |
| siamese.png            | 暹罗猫     | 尖耳、窄脸、深色面罩           |
| american-shorthair.png | 美短银虎斑 | 银灰色、深色条纹、绿色眼睛     |
| persian.png            | 波斯猫     | 白色蓬松长毛、小耳、粉色鼻子   |
| calico.png             | 三花猫     | 黑白橘不对称色块、左右异色耳朵 |

橘猫和三花猫按常见毛色类型归类，其余按品种归类。名称与标识的权威配置在 `features/avatars/presets.ts`，图片映射在 `features/avatars/images.ts`。

保持原有布局尺寸：聊天标题 22 像素、侧栏及选择器 34 像素、置顶及资料头像 56 像素。原图约占 13 MiB 打包体积，无远程请求、运行时生成或新增依赖；浏览器缓存同一头像资源，列表最多 64 位助手。
