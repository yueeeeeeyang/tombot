# 猫咪预设头像

运行时头像画在 `features/avatars/CatGraphic.tsx`，是随应用打包的矢量贴纸，不请求网络，也不再附带 PNG。八款毛色定义在 `features/avatars/palette.ts`，深浅主题使用同一套颜色，不会反相。名称和标识的权威配置在 `features/avatars/presets.ts`。

姿态由 `features/avatars/pose.ts` 决定：静息、工作中、悬停。活动状态放在 `features/avatars/activity.ts` 的内存表里，给以后的传输层写入。桌面端 README 的「状态与后续服务端接入」写了调用方式和当前为什么不会自己进入工作中。

同目录的 [prompts.json](./prompts.json) 是最初生成静态头像时的提示词，只留作品种外观记录，运行时不会读取。

| 预设               | 名称       | 区分特征                       |
| ------------------ | ---------- | ------------------------------ |
| bombay             | 孟买猫     | 黑色短毛、琥珀色眼睛           |
| orange-tabby       | 橘猫       | 姜黄色、额头虎斑纹、奶油色嘴部 |
| british-shorthair  | 英短蓝猫   | 蓝灰色、圆脸、铜色眼睛         |
| ragdoll            | 布偶猫     | 长毛、白色倒 V 脸纹、蓝色眼睛  |
| siamese            | 暹罗猫     | 尖耳、窄脸、深色面罩           |
| american-shorthair | 美短银虎斑 | 银灰色、深色条纹、绿色眼睛     |
| persian            | 波斯猫     | 白色蓬松长毛、小耳、粉色鼻子   |
| calico             | 三花猫     | 黑白橘不对称色块、左右异色耳朵 |

橘猫和三花猫按常见毛色类型归类，其余按品种归类。

尺寸保持会话标题 22 像素、侧栏和选择器 34 像素、置顶和资料头像 56 像素。系统开启减弱动效时使用静止的静息姿势。最多 64 位助手，动画只用变换，避免每只猫各占一套图片。
