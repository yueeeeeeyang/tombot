# 猫咪预设头像

运行时用 `frames/` 里的 256×256 透明 PNG。22、34、56 像素在 3 倍屏下不超过 168 像素，256 已经够用，因此不再打包原来的 1254 像素大图。深浅主题用同一套帧，不反色，也不从网络加载。名称和标识的权威配置在 `features/avatars/presets.ts`，帧地址在 `features/avatars/frames.ts`。

帧是以最初的原图为参照生成的：闭眼和半闭眼先按原图改画，再对齐并只保留眼部，叠回原图。竖耳和抽耳是整帧预渲染，由原图沿耳根做平滑弯曲，避免实时旋转留下接缝。睁眼、耳朵放下的那一帧，由无耳头部和左右耳在 0 度叠回去，和其余帧对齐。眨眼时只换眼部叠层，可以盖在竖耳或抽耳上面。

姿态由 `features/avatars/pose.ts` 决定，眨眼和抽耳共用 `features/avatars/catMotion.ts` 的一个时钟。帧全部解码成功后才开始换图；失败会记错误并停在睁眼原图。页面隐藏时时钟暂停，恢复后不补做错过的眨眼。系统开启减弱动效时只显示睁眼原图。桌面端 README 写了工作中状态为什么不会在保存草稿时出现。

同目录的 [prompts.json](./prompts.json) 是最初大图的生成提示词，运行时不会读取。

| 预设               | 名称       | 区分特征                       |
| ------------------ | ---------- | ------------------------------ |
| bombay             | 孟买猫     | 黑色短毛、琥珀色眼睛           |
| orange-tabby       | 橘猫       | 姜黄色、额头虎斑纹、奶油色嘴部 |
| british-shorthair  | 英短蓝猫   | 蓝灰色、圆脸、铜色眼睛         |
| ragdoll            | 布偶猫     | 长毛、白色倒 V 脸纹、蓝色眼睛  |
| siamese            | 暹罗猫     | 尖耳、窄脸、深色面罩           |
| american-shorthair | 美短银虎斑 | 银灰色、深色条纹、绿色眼睛     |
| persian            | 波斯猫     | 白色蓬松长毛、小耳、粉色鼻子   |
| calico             | 三花猫     | 黑白橘不对称色块、左右异色耳朵 |

橘猫和三花猫按常见毛色类型归类，其余按品种归类。

尺寸保持会话标题 22 像素、侧栏和选择器 34 像素、置顶和资料头像 56 像素。列表最多 64 位助手，帧由浏览器缓存。布偶和暹罗的竖耳、抽耳幅度较小，避免耳尖被画布裁掉。孟买和三花的闭眼线条对比不高，但缩小后仍能看出。
