# 猫咪预设头像

运行时头像是同目录的透明 PNG 原图，由 `features/avatars/images.ts` 映射，随应用打包，不请求网络。深浅主题使用同一张图，不反色。名称和标识的权威配置在 `features/avatars/presets.ts`。

动画不改原图：静息从下巴轻微呼吸并小幅摆动，悬停时整张头按弹簧转向指针，进入时轻弹一下，按下时压扁，工作中点头并在角落显示输入点。没有单独的闭眼或竖耳图层，所以不做眨眼和抽耳朵。姿态由 `features/avatars/pose.ts` 决定，活动状态放在 `features/avatars/activity.ts`。桌面端 README 的「状态与后续服务端接入」写了调用方式，以及为什么保存草稿不会进入工作中。

同目录的 [prompts.json](./prompts.json) 是这些 PNG 的生成提示词，运行时不会读取。

| 文件                   | 预设名称   | 区分特征                       |
| ---------------------- | ---------- | ------------------------------ |
| bombay.png             | 孟买猫     | 黑色短毛、琥珀色眼睛           |
| orange-tabby.png       | 橘猫       | 姜黄色、额头虎斑纹、奶油色嘴部 |
| british-shorthair.png  | 英短蓝猫   | 蓝灰色、圆脸、铜色眼睛         |
| ragdoll.png            | 布偶猫     | 长毛、白色倒 V 脸纹、蓝色眼睛  |
| siamese.png            | 暹罗猫     | 尖耳、窄脸、深色面罩           |
| american-shorthair.png | 美短银虎斑 | 银灰色、深色条纹、绿色眼睛     |
| persian.png            | 波斯猫     | 白色蓬松长毛、小耳、粉色鼻子   |
| calico.png             | 三花猫     | 黑白橘不对称色块、左右异色耳朵 |

橘猫和三花猫按常见毛色类型归类，其余按品种归类。

尺寸保持会话标题 22 像素、侧栏和选择器 34 像素、置顶和资料头像 56 像素。原图按这个尺寸缩小显示，不做放大。系统开启减弱动效时使用静止的静息姿势。列表最多 64 位助手，同一张原图由浏览器缓存。
